# Native Tile updates

Public update feed and signed macOS downloads for Native Tile.

Choose Stable, Beta, or Nightly in Native Tile → Settings → General → Updates.
Automatic checks are optional. Stable users receive only stable releases; Beta
also includes beta builds; Nightly includes all three channels. Returning to
Stable waits for a newer stable build and never silently downgrades the app.

The app verifies update archives with Sparkle Ed25519 signatures and Apple code
signing. Window data and diagnostics are not uploaded during update checks.

There are no releases yet. The feed will populate when a signed release is published.
